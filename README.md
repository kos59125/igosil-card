# 囲碁シル 定石カード最適化ツール

囲碁シルの「定石カードバトル」で、相手（黒）が右上・左下に置いたカードに対して、
自分（白）が左上 (A) と右下 (B) に置くカードと反転の組み合わせを KataGo の勝率で探索するツールです。

## 構成

| ファイル | 役割 |
|---|---|
| `server.py` | ローカルサーバー（標準ライブラリのみ）。UI 配信、KataGo analysis エンジンの常駐・呼び出し、カードリストの取得・保存 |
| `static/index.html` | ブラウザ UI（盤面表示、手動配置・反転、勝率計算、最適化、カード編集） |
| `analysis.cfg` | KataGo analysis 用の最小設定 |
| `data/cards.json` | カードリスト（「カードリスト更新」で作成・更新） |

ブラウザから KataGo を直接動かせないことと、記事ページを CORS 制約なしで取得するため、小さな Python サーバーを挟んでいます。

## 導入と起動

必要なものは **Python 3.8 以上**（追加パッケージ不要）と **KataGo（実行ファイル + ネットワーク）** の 2 つです。

### 1. KataGo の導入

**画面からダウンロードできます（おすすめ）。** `server.py` を KataGo の指定なしで起動し（手順 2・3）、ブラウザで「設定」タブの「KataGo の導入」を開きます
（ヘッダーの「未設定」バッジをクリックしても開きます）。

1. OS はブラウザから自動で判定されます（変更も可）。「リリース一覧を取得」→ バックエンドを選んで「ダウンロードして展開」
   - 既定では、その OS 用の OpenCL 版がある最新リリースを選びます（NVIDIA 専用のリリースは飛ばします）
2. 「ネットワーク一覧を取得」→ ネットワークを選んで「ダウンロード」（「最も強い」「軽い（b18c384nbt）」のおすすめボタンあり）
3. 両方そろうと自動で KataGo を起動します。パスは `katago/settings.json` に保存され、次回からは `py server.py` だけで起動します

ダウンロード先はこのツールのフォルダの `katago/` です。macOS 用の実行ファイルがリリースに無い場合は、Homebrew（`brew install katago`）で入れて
「パスを手動で指定する」から指定してください。以下は手動で導入する場合の説明です。

KataGo は「実行ファイル」と「ネットワーク（学習済みモデル、`.bin.gz`）」を別々に入手します。

#### 実行ファイル

[KataGo の GitHub Releases](https://github.com/lightvector/KataGo/releases) から、OS とハードウェアに合った zip をダウンロードして任意のフォルダ（例: `C:\KataGo`）に展開します。
Windows 用の zip はファイル名に `windows` と、使うバックエンド名（`opencl` / `cuda` / `trt` / `eigen`）が入っています。

| 環境 | 選ぶバックエンド | 備考 |
|---|---|---|
| NVIDIA の GPU | CUDA（または OpenCL） | CUDA 版は CUDA Toolkit と cuDNN（9.8 以上推奨）の導入が必要。追加導入なしで動かしたい場合は OpenCL 版 |
| AMD / Intel の GPU | OpenCL | 最新リリースが NVIDIA 向けのみの場合は、リリースノートの案内に従い一つ前のリリースを使う |
| GPU なし | Eigen AVX2（古い CPU なら Eigen） | CPU のみ。解析は遅くなるので visits は 1 のままを推奨 |

- OpenCL 版は**初回起動時に GPU のチューニング**が自動で走り、数分かかることがあります（その間、画面上部のバッジは黄色の「起動中」のままです）。
- CUDA 版で `cudnn64_*.dll` などが見つからないエラーが出る場合は、CUDA / cuDNN が未導入か PATH に入っていません。OpenCL 版に切り替えるのが手軽です。

#### ネットワーク

[KataGo のネットワーク一覧（katagotraining.org/networks）](https://katagotraining.org/networks/) から **「Network File」**（`.bin.gz`）をダウンロードし、KataGo と同じフォルダなどに置きます。

- GPU（特に CUDA）がある場合: ページ上部の「strongest confidently-rated network」で問題ありません。
- CPU（Eigen）や非力な GPU の場合: 最新の大型ネットワークは重いので、一覧から **`b18c384nbt`** の付いたネットワーク（`kata1-b18c384nbt-s….bin.gz`）など軽めのものを選ぶと速く動きます。
- このツールは大量の局面を 1 visit 程度で評価するため、強さより速さを優先したネットワークでも十分実用になります。

#### 設定（任意）

同梱の `analysis.cfg` は最小設定です。性能に合わせて次の値を調整できます。

- `numAnalysisThreads`: 同時に解析する局面数。GPU なら 8〜32、CPU なら CPU コア数程度
- `numSearchThreadsPerAnalysisThread`: 1 局面あたりの探索スレッド数。visits が 1〜数十なら 1〜2 で十分
- `nnMaxBatchSize`: GPU 向け。`numAnalysisThreads × numSearchThreadsPerAnalysisThread` 以上にする

### 2. 起動（Windows / PowerShell）

1. **Python を入れる**（未導入の場合）

   ```powershell
   winget install Python.Python.3.14
   ```

   [python.org](https://www.python.org/downloads/windows/) のインストーラーでも構いません（その場合は「Add python.exe to PATH」にチェック）。
   インストール後は **PowerShell を開き直して**から確認します。

   ```powershell
   py --version
   ```

   - Windows では `python3` ではなく **`py`**（または `python`）を使います。
   - `python` と打つと Microsoft Store が開く場合は、「設定 → アプリ → アプリの詳細設定 → アプリ実行エイリアス」で「python.exe」「python3.exe」をオフにします。

2. **このツールを入手する**

   ```powershell
   git clone https://github.com/kos59125/igosil-card.git C:\igosil-card
   ```

   Git が無い場合は `winget install Git.Git` で入れるか、GitHub の「Code → Download ZIP」で取得して展開します。

3. **起動する**（パスとネットワークのファイル名は、実際に置いた場所・ダウンロードしたファイル名に合わせて変更）

   ```powershell
   cd C:\igosil-card
   py server.py --katago C:\KataGo\katago.exe --model C:\KataGo\kata1-b18c384nbt.bin.gz
   ```

   画面からダウンロードした場合は、パスの指定なしで起動できます（`py server.py`）。

   毎回パスを書くのが面倒な場合は環境変数でも指定できます。

   ```powershell
   $env:KATAGO_PATH  = "C:\KataGo\katago.exe"
   $env:KATAGO_MODEL = "C:\KataGo\kata1-b18c384nbt.bin.gz"
   py server.py
   ```

   - パスに空白を含む場合は `"C:\Program Files\KataGo\katago.exe"` のように引用符で囲みます。
   - 環境変数をずっと使いたい場合は `[Environment]::SetEnvironmentVariable("KATAGO_PATH", "C:\KataGo\katago.exe", "User")` で保存できます（新しい PowerShell から有効）。

4. ブラウザで http://127.0.0.1:8765/ を開きます。画面上部のバッジが緑の「準備完了」になれば使えます。
5. 終了は PowerShell で `Ctrl + C`。

### 3. 起動（macOS / Linux）

```sh
# macOS は Homebrew でも KataGo を入れられます: brew install katago
python3 server.py --katago /path/to/katago --model /path/to/model.bin.gz
# または環境変数 KATAGO_PATH / KATAGO_MODEL / KATAGO_CONFIG
```

ブラウザで http://127.0.0.1:8765/ を開きます。

### KataGo なしで試す

画面だけ確認したい場合は KataGo 不要のモックで起動できます（勝率は疑似値）。

```sh
py server.py --mock        # Windows
python3 server.py --mock   # macOS / Linux
```

`--mock-delay 0.05` を付けると 1 局面あたりの解析時間を擬似的に遅くできます。

### その他のオプション

| オプション | 既定値 | 内容 |
|---|---|---|
| `--port` | 8765 | 待ち受けポート |
| `--host` | 127.0.0.1 | 待ち受けアドレス（自分の PC からのみアクセス可能） |
| `--config` | `analysis.cfg` | KataGo の設定ファイル（環境変数 `KATAGO_CONFIG` でも指定可） |

## 使い方

- **手動配置**: 盤の下の 4 つの隅でカードと「反転」を選ぶと、その都度勝率（白視点）を計算します。
  カードの選択ボックスは「属性 ▸ 動物 ▸ カード」の折りたたみ一覧で、文字を入力して絞り込めます。属性・動物（それぞれ 1 つだけ選択）は一覧の見出しや上部のボタンをクリックすると
  入力欄に条件（チップ）として入り、組み合わせて絞り込めます（↑↓・Enter で選択、Esc で閉じる、Backspace でチップを削除）。
  「SGF をコピー」で現在の初期配置を SGF（石は AB/AW、KM は実質コミ、黒番、カード名をコメント）としてクリップボードにコピーできます。
- **最適化**: 「最適化」タブで条件を決めて「最適な配置を探す」。
  - 使う属性（地・宙・海）の絞り込み。「相手に有利な属性のみ」で 地 > 海 > 宙 > 地 の相性から自動設定
  - 所持カードのみ / 反転も試す / 片方の隅を固定
  - 探索方法: 全探索、または高速な 2 段階（各隅を単独評価して上位 K 件ずつ → K×K 通りを評価）
  - 結果の行をクリックすると盤面に反映
  - 実行中は 1 局面終わるごとに、進捗・局面/秒・残り時間の目安・暫定最高の組み合わせを表示（評価ログにバッチごとの記録）
  - 評価ログの先頭と結果欄の上に、入力パラメーター（相手の配置、KataGo のバージョンとモデル、visits、探索方法、属性などの条件）を表示
  - 同じ入力パラメーターで再実行すると、前回の結果をキャッシュから即座に表示（ブラウザのセッション内のみ。タブを閉じると消えます）
  - 「すべてクリア」や相手のカード・反転を変えたときは、解析結果とログをクリア（実行中なら中止）
- **防御の最適化**（「防御の最適化」タブ）: 自分が防御側（黒、右上 = A・左下 = B、カードは表示通り）のとき、
  A・B に 3 枚ずつ登録するカードを探します。対局では A・B から 1 枚ずつが独立に等確率で選ばれ（9 通り、各 1/9）、
  相手（挑戦側、白）は置かれたカードを見て任意のカードから最善の応手をする、という前提で期待勝率を最大化します。
  - 評価の順序（有望なものから評価し、いつ止めても暫定の答えが出る。続ければ最終的に全探索）
    - 自分のカードの勝率 s と、相手の応手カード（左上・右下の候補 × 向き）の勝率 t を、どちらも 50% から始める
    - 1 局面ごとに、自分の組（A × B × 向き）を重み s(A)×s(B) で、その組への相手の応手（左上 × 右下）を重み t(左上)×t(右下) でサンプリングして評価する。
      自分の組の向きは「両方反転なし」と「A のみ反転」の 2 通り（両方反転は相手の配置次第で同義）
    - 組の値 = これまで評価した応手の中で最も悪い黒の勝率（全応手を評価すると正確な最悪ケース。それまでは「≤」付きの上限として表示）
    - s(A)・s(B) は min(s, 黒の勝率) に、t は max(t, 白の勝率) に更新（負ける応手が見つかった自分のカードは後回し、強い応手は早く試す）
    - 重みはカードごとの値の積なので、数億通りの組み合わせ全体の表は持たず、各隅を独立にサンプリングする（評価済みかどうかは組ごとのビットマップで管理）
  - 最後に、A から別カード 3 枚・B から別カード 3 枚を選び、9 組の最悪ケース勝率の平均が最大になる組み合わせを厳密に求める
    （A の 3 枚組を全列挙すると B は列ごとに独立に選べるため。B の向きは (A^x, B^y) = (A^(x xor y), B) として評価済みの値から求める）
  - 結果は「採用する 6 枚（A 3 枚 + B 3 枚）」の候補を期待勝率の順に上位 20 件表示（実行中も暫定の順位を更新し、新しく入った候補を強調表示）。
    行を選ぶと 3 × 3 の内訳（各組の勝率と相手の最善応手）を表示し、マスをクリックすると盤面に反映。各組の評価の一覧は参考として折りたたみ表示
  - 実行中も 5 秒ごとに、評価済みの組から暫定の最適な 3 + 3 を表示します。途中で中止しても暫定の答えが残り、
    同じ条件で再実行すると続きから評価します（セッション内）。全部終わった条件は即座に再表示
  - 計算量が大きい（自分の組の数 × 相手の応手 約 1.6 万通り）ので、必要に応じて属性・所持・向きの条件で自分の候補を絞ってください。
    実行前に評価する局面数の上限と、直近の速度からの所要時間の目安を表示します
- **カード一覧**: 所持チェック、手動でのカード追加・編集（盤クリックまたは SGF で手順入力）、JSON 書き出し/読み込み。
- **カードリスト更新**: ヘッダーのボタンで [gonote の記事](https://gonote-app.com/article/TSqUCWy46aAwyoUyrix2) を取得してマージします。
  記事の「カード表（名称・属性・配置）」と直後の碁盤 SGF を対応付け、各分岐の最終手のコメント（カード名）までの手順をそのカードの手順とします。
  SGF に見つからないカードは警告を出し、手順は手動入力になります。
  手動で編集したカードの手順は保持され、記事から消えたカードは削除せず「退役」扱いになります。
  サーバーから取得できない場合は「ページ貼り付けで更新」で、ブラウザで開いた記事の HTML を貼り付けて解析できます。
- **設定**: visits（既定 1）、同時に送る局面数、カード取得元 URL。

## 対局条件（固定）

19 路、コミ 6.5 目、日本ルール。4 隅にカードを置いた後は常に黒番から始まります（カードの手順がどちらで終わっているかは無関係）。

定石カードの手順中に取られた石（アゲハマ）は、日本ルールでは 1 個 1 目なので、局面ごとにコミへ加減して KataGo に渡します
（実質コミ = 6.5 + 白のアゲハマ − 黒のアゲハマ）。自分の隅では白黒が反転するため、アゲハマの持ち主も入れ替わります。

## 属性相性

地 > 海 > 宙 > 地。自分の 2 枚 × 相手の 2 枚の全 4 組について、有利 +1・同属性 0・不利 −1 を合計した値を相性スコアとして表示します（最適化結果では勝率が同じ場合の並び順にも使用）。

## カードの座標と反転

カードの手順は、定石一覧に描かれている相手側の配置（防御時配置）のまま、隅・色とも SGF 座標で保存します（描かれた隅は記事の碁盤の表示位置 `focusMode`、無ければ石の重心から判定）。
右上・左下（相手）には表示通りの色で、左上・右下（自分・挑戦時配置）には白黒を反転して配置します。
配置先の隅へは盤ごと時計回りに回転して当てはめます（右上に描かれたカードなら、右下 90°・左下 180°・左上 270°）。「反転」はその隅の対角線で折り返します。
4 隅の石を合わせた局面で石の重なりや呼吸点ゼロの石が生じる配置はできません。相手（右上・左下）の配置が優先で、
自分の隅（左上・右下）では衝突するカード・向きがグレーアウトされます。相手の配置を変えて自分のカードが置けなくなった場合は、
反対の向きで置ければ自動で反転し、どちらの向きでも置けなければ外します。最適化でも衝突する組み合わせは評価しません。
